# Shark 喷雾风扇视频库

独立专题页面，包含 35 条 TikTok 关联视频，按 FastMoss 原表的“该商品销量”降序排列。

在线页面：https://ctxyytx123-ui.github.io/shark-video-library/

## 本站直接播放

35 条视频均已下载并上传到本站 `videos/` 目录，通过原生 HTML 视频播放器播放，不使用 TikTok iframe，也不从 TikTok 服务器加载视频。

视频统一为 H.264 / AAC MP4，启用 fast-start，按点击加载。每条提供本站视频下载和原作者来源入口。

GitHub Pages 本身的访问情况仍取决于访问者所在网络；移除 TikTok 播放依赖不等于保证所有国内网络都能稳定访问 GitHub Pages。

## 数据说明

- 数据来源：用户提供的 FastMoss 导出表，整理日期 2026-11-20；不是实时数据。
- “该商品销量”不等同支付订单数。销售额、投放消耗保留原表数值，币种原表未注明。
- 5 条归纳基于平台字幕与发布文案；其余 30 条归纳仅基于发布文案。保存视频不会自动改变原有归纳依据。
- 产品体验、库存、优惠和配送为原作者发布时的表述，不表示当前仍然有效。

本项目独立发布，不与其他视频库合并。

## 文件

- `index.html`：页面及内嵌封面、归纳数据。
- `videos/*.mp4`：35 条本站视频。
- `视频销量排序.csv`、`视频归纳.json`：排序表和结构化归纳。

视频及创作内容的权利归原作者及相应权利人所有，页面保留原作者及原视频来源。
