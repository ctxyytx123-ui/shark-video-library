# Shark 喷雾风扇视频库

独立专题页面，包含 35 条 TikTok 关联视频，默认按所提供 FastMoss 表格的“该商品销量”从高到低排列。

## 浏览页面

https://ctxyytx123-ui.github.io/shark-video-library/

提供视频封面、TikTok 官方播放器与原视频入口、中英文发布文案、内容归纳、分类筛选、搜索和销量表下载。

本项目独立发布，不与其他视频库合并。

## 数据与归纳说明

- 来源：用户提供的 FastMoss 导出表，整理日期 2026-11-20。
- “该商品销量”为原表商品销量，不等同支付订单数；数据不是实时数据。
- 销售额与投放消耗保留原表数值，原表未注明币种。
- 5 条已获取平台英文字幕，其余 30 条仅依据发布文案归纳；未补造未获取的镜头或口播。
- TikTok 播放器需要网络及当地可用的 TikTok 服务，可能受登录或地区限制。
- 产品体验、优惠、库存及配送为原作者发布时的表述，不表示当前仍然有效。

## 文件

- `index.html`：独立页面，封面和归纳数据已内嵌。
- `视频销量排序.csv`：销量降序表。
- `视频归纳.json`：结构化归纳数据。

所有视频及相关创作内容的权利归原创作者及相应权利人所有。本项目保留原视频入口，不托管视频文件。
